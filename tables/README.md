# Supplementary tables

The files in this directory are the complete machine-readable table outputs used by the manuscript and Technical Appendix. Tables S1–S11 are the submission-facing supplementary tables; numbered files 01–42 are the full upstream analysis outputs retained for provenance.

- Use `SUPPLEMENTARY_TABLES_INDEX.csv` for the S1–S11 crosswalk.
- CSV values are preserved from the deterministic analysis outputs; do not manually retype them into the manuscript.
- `33_country_level_dataset.csv` is the country-level analysis dataset, not individual-level data.
- `38b_source_classification_exemplars.csv` contains audit exemplars of public metadata values, not patient identifiers.
